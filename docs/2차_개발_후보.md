# 2차 개발 후보

## 요청하신 항목
1. **PDF 버전 간 차이 자동 비교** — 두 버전의 페이지를 이미지로 바꿔 픽셀 차이를 색으로 겹쳐 표시합니다. 텍스트 레이어를 비교해 바뀐 문구(전성분·용량·바코드 번호)도 목록으로 보여줍니다. 지금의 "나란히 비교" 화면을 확장하는 방식입니다.
2. **문안 맞춤법 검사** — PDF에서 문구를 뽑아 맞춤법·띄어쓰기 오류를 표시합니다. 화장품 표시 사항(전성분 표기 순서, 용량 단위 mL·g, 사용기한·제조번호 문구, 필수 기재 사항 누락)도 사내 규칙 사전으로 검사합니다.
3. **ERP 연동** — 품목코드, 발주서 번호, 입고 검수 결과를 ERP와 주고받습니다. 대장 엑셀의 자동 전송부터 시작해 API 연동으로 넓혀 갑니다.

## MVP를 만들며 추가로 나온 후보
4. 업체가 수정 요청이나 승인을 하면 **내부 담당자에게 알림** (메일·카카오워크·슬랙)
5. **카카오 알림톡**으로 업체 알림 (메일을 잘 확인하지 않는 업체 대응)
6. 승인할 때 **이메일 인증번호** 추가 확인 (본인 확인 강화)
7. 업체가 메일·전화로 승인한 경우, 내부 담당자가 **증빙을 첨부해 대리 기록**
8. **자동 백업**: 매주 대장 엑셀과 DB 덤프를 사내 드라이브로 보관
9. 해외 바이어용 **영문 화면**
10. 링크 **만료일 연장** 기능 (지금은 폐기 후 재발급)
11. 프로젝트 **템플릿·일괄 생성** (같은 품목의 용기·단상자·라벨을 한 번에 만들기)
