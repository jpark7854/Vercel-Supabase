# 디자인 포털 — 내부 담당자 사용 안내

> 접속: 포털 주소 → 회사 이메일·비밀번호로 로그인. 첫 로그인 후 **[내 계정]에서 비밀번호를 바꾸세요.**

## 한눈에 보는 업무 흐름

```
[설정] 브랜드·업체·담당자 등록 (관리자, 최초 1회)
   ↓
[프로젝트] 새 프로젝트 만들기 (브랜드 / 품목 / 부자재 / 생산 예정 주차)
   ↓
[공유 링크] 업체 담당자별 링크 발급 (보기 / 코멘트 / 승인) → 비밀번호는 다른 채널로 전달
   ↓
[새 버전 업로드] 시안 PDF + 작업지시서 → "지금 업체에 발송" → 상태: 회신 대기
   ↓
업체 회신 ─ 수정 요청 → v2 업로드·발송 (반복)
         └ 전원 승인 → 🔒 최종 승인본 자동 확정 → 상태: 승인
   ↓
[🖨 인쇄·발주 진행] (승인 전에는 눌리지 않음)
   ↓
부자재 업체에 "보기" 링크로 최종 승인본 공유 → [입고 검수]에서 실물과 대조
```

---

## 1. 처음 준비 (관리자)
**[설정]** 메뉴에서:
1. **브랜드** 추가 (예: 론지화장품)
2. **업체** 추가 + 종류 선택 (브랜드사·제조사·용기·튜브·단상자·라벨·기타)
3. **업체 담당자** 추가 (업체, 이름, 이메일) — 링크는 담당자 단위로 발급됩니다
4. **내부 계정** 추가 → 화면에 한 번만 나오는 임시 비밀번호를 본인에게 직접 전달

## 2. 프로젝트 만들기
**[프로젝트] → [＋ 새 프로젝트]**
- 브랜드 / 부자재 / 품목 / 생산 예정 월·주차 / 다음 할 일 / 비고
- 파일명은 자동으로 `브랜드_품목_부자재_v번호_YYYYMMDD.pdf` 가 됩니다. 띄어쓰기는 `-` 로 바뀝니다.

## 3. 업체 링크 발급 — [공유 링크] 탭
| 권한 | 업체가 할 수 있는 일 | 이럴 때 |
|---|---|---|
| 보기 | 최신본 보기·다운로드 | 최종 승인본을 부자재 업체에 넘길 때 |
| 코멘트 | 보기 + 코멘트 + 수정 요청 | 의견은 받되 승인 권한은 없는 업체 (예: 라벨 인쇄소) |
| 승인 | 보기 + 코멘트 + 수정 요청 + **승인** | 반드시 검수해야 하는 곳 (예: 제조사, 브랜드사) |

- **승인 권한 링크가 여러 개면 모두 승인해야** 최종 승인본이 됩니다. 제조사가 검수하기 전에 라벨부터 인쇄하는 일을 막으려면, 제조사에 **승인** 권한을 주세요.
- 만료일은 기본 60일입니다. 비우면 무기한입니다.
- 발급 직후 화면에 **링크와 비밀번호가 한 번만** 표시됩니다.
  - ✅ 링크는 메일, 비밀번호는 카카오톡·문자·전화처럼 **반드시 다른 채널**로 보내세요.
  - 비밀번호는 다시 볼 수 없습니다. 분실하면 **폐기 → 재발급**합니다.
- 담당자가 바뀌거나 거래가 끝나면 **[폐기]** 를 누르세요. 즉시 접속이 막힙니다.

## 4. 새 버전 업로드 — [⬆ 새 버전 업로드]
1. **시안 PDF** 선택 (PDF만 가능, 최대 50MB). AI 파일은 일러스트레이터에서 *다른 이름으로 저장 → Adobe PDF* 로 저장한 뒤 올립니다.
2. **작업지시서** (PDF·엑셀, 여러 개 가능)를 같은 버전에 묶어서 올립니다.
3. **발송 목적** 선택: 시안 검토 / 작업지시서 / 최종 승인본 / 발주서 / 자료 요청
4. **메모** (업체에도 보임): 예) "v1 대비 전성분 순서 수정"
5. **지금 업체에 발송** 체크 → 업로드와 동시에 업체에 메일 알림이 가고, 상태가 **회신 대기**로 바뀝니다.
   - 체크하지 않으면 **발송 예정**으로 저장됩니다. 나중에 프로젝트 화면의 **[업체에 발송]** 으로 보냅니다.
- 이전 버전은 삭제되지 않고 보관됩니다. **업체에는 발송된 최신본만** 보입니다.

## 5. 회신 확인
- **대시보드**: 상태별 건수와 **응답 대기 중인 업체 목록**이 보입니다. 경과일이 3일 이상이면 빨간색입니다.
  3일간 응답이 없으면 매일 오전 9시에 리마인더 메일이 자동으로 나가고, 이후 3일마다 반복됩니다.
- **프로젝트 화면 상단 "회신 현황"**: 업체별로 승인 / 수정 요청 / 대기 상태와 회신 메시지를 보여줍니다.
- **[파일 보기·코멘트] 탭**: 업체가 찍은 핀 코멘트를 확인하고 답글을 남길 수 있습니다.
- **[버전 이력] → [나란히 비교]**: 두 버전을 나란히 놓고 같은 페이지를 확인합니다.

## 6. 최종 승인과 인쇄·발주
- 승인 권한 업체가 **전원 승인**하면 그 버전이 자동으로 **🔒 최종 승인본**이 됩니다. 수정·삭제는 불가능합니다.
- 그때부터 **[🖨 인쇄·발주 진행]** 버튼이 활성화됩니다. 누르면 진행 시각과 담당자가 기록됩니다. 되돌릴 수 없습니다.
- 승인 후 부자재 업체에 파일을 넘길 때는 **보기** 권한 링크를 발급합니다. 업체에는 최종 승인본만 보입니다.

## 7. 승인 후 수정이 필요할 때 / 중단할 때
- **개정 시작**: 승인된 프로젝트에서 사유를 입력하고 누르면 새 버전을 올릴 수 있습니다. 인쇄·발주 버튼은 다시 잠기고, 이전 승인본과 개정 사유는 기록에 남습니다.
- **반려 처리**: 프로젝트를 중단하거나 취소할 때 사유와 함께 처리합니다. 다시 진행하려면 **개정 시작**을 누릅니다.

## 8. 입고 검수 — [입고 검수] 메뉴 (휴대폰 추천)
- 브랜드나 품목으로 검색한 뒤 **[승인본 PDF 열기]** 를 누르면 최종 승인본이 바로 열립니다.
- 카드에서 승인자·승인 일시·인쇄 발주 일시를 함께 확인합니다.
- "⚠ 개정 진행 중"이 보이면, 입고품이 어느 버전 기준인지 확인하세요.

## 9. 발송·승인 대장 — [발송·승인 대장] 메뉴
- 한 줄은 "한 버전을 한 업체 담당자에게 보낸 기록"입니다. 컬럼은 발송일, 업체, 담당자, 브랜드, 품목·부자재, 파일명, 버전, 승인 상태, 생산 예정 주차, 회신일, 승인자, 발송 목적, 발송 방법, 다음 할 일, 비고입니다.
- **발송 방법 / 다음 할 일 / 비고**는 표에서 바로 고치고 [저장]합니다.
- **[⬇ 엑셀] [⬇ CSV]** 로 기간·검색 조건에 맞게 내려받습니다. 무료 플랜은 자동 백업이 없으니 **매월 엑셀을 내려받아 보관**하세요.

## 10. 활동 기록 (분쟁 대비)
- 업로드, 발송, **업체 열람**, 다운로드, 코멘트, 수정 요청, 승인(서명 이름·IP), 메일 발송, 링크 발급·폐기가 모두 자동으로 기록됩니다.
- 이 기록은 **누구도 수정하거나 삭제할 수 없습니다.** "받은 적 없다"는 분쟁이 생기면 [활동 기록]에서 해당 업체의 **메일 발송 → 업체 접속 → 열람** 기록을 확인하세요.

## 자주 묻는 질문
| 질문 | 답 |
|---|---|
| 업로드가 안 돼요 | PDF가 아닌 파일(AI·PSD), 50MB 초과, 이미 승인된 프로젝트(→ 개정 시작) 중 하나인지 확인하세요 |
| 업체가 메일을 못 받았대요 | [활동 기록]에서 "메일 발송/실패"를 확인하세요. 스팸함을 확인해 달라고 하거나, 링크를 카카오톡으로 직접 보내도 됩니다 |
| 업체가 비밀번호를 잊었어요 | [공유 링크] 탭에서 해당 링크를 폐기하고 새로 발급하세요 |
| 승인했는데 최종 승인본이 안 돼요 | 승인 권한 링크가 여러 개면 전원이 승인해야 합니다. 화면 상단 "회신 현황"에서 대기 중인 업체를 확인하세요. 더 이상 승인할 필요가 없는 업체라면 그 링크를 폐기하세요 |
| 잘못 올린 버전을 지우고 싶어요 | 기록 보존을 위해 삭제할 수 없습니다. 올바른 파일을 새 버전으로 올리고 메모에 사유를 적어 주세요 |
