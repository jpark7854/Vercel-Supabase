# 명성코퍼레이션 디자인 포털 — 업체 담당자 사용 안내

디자인 시안·작업지시서·최종 승인본을 **메일 첨부 대신 포털에서** 확인하고 회신하는 방법입니다.
회원가입이나 프로그램 설치 없이 **휴대폰·PC 브라우저**에서 바로 사용할 수 있습니다.

---

### ① 접속하기
1. 메일로 받은 **[포털에서 파일 보기]** 버튼(또는 링크)을 누릅니다.
2. **비밀번호**를 입력합니다. 비밀번호는 보안을 위해 메일에 넣지 않고, 담당자가 **카카오톡·문자·전화 등으로 따로** 보내드립니다.
   - 5회 틀리면 15분간 잠깁니다.
   - 링크는 **담당자 한 분 전용**입니다. 회신 기록이 링크 주인의 이름으로 남으니 다른 분께 전달하지 마세요. 다른 분이 보셔야 하면 명성코퍼레이션 담당자에게 요청해 주세요.

### ② 파일 확인하기
- 화면에는 **항상 최신 버전 한 개만** 보입니다. 예전 파일과 헷갈릴 일이 없습니다.
- ◀ ▶ 로 페이지를 넘기고, ＋ － 로 확대·축소합니다. **[새 창에서 열기]** 를 누르면 크게 볼 수 있습니다.
- **[⬇ 시안 PDF 내려받기]**, **[⬇ 작업지시서]** 로 파일을 저장할 수 있습니다.

### ③ 의견 남기기 (코멘트)
1. **[📍 파일 위에 위치 찍기]** 를 누른 뒤, 고칠 곳을 파일 위에서 누릅니다.
2. 내용을 적고 **[코멘트 등록]** 을 누릅니다. 파일 위에 번호 핀이 표시됩니다.
   - 위치를 찍지 않으면 해당 페이지 전체에 대한 의견으로 남습니다.

### ④ 회신하기 — 화면 아래 버튼
| 버튼 | 언제 | 입력할 것 |
|---|---|---|
| **수정 요청** | 고칠 부분이 있을 때 | 수정 내용, 이름 |
| **승인** | 이대로 인쇄·생산해도 될 때 | **이름 직접 입력** + "최종 시안을 확인했으며 인쇄·생산 진행에 동의" 체크 |

- 승인하면 **승인자 이름과 승인 일시가 자동 기록**됩니다.
- 승인자가 여러 명이면 **모두 승인했을 때** 최종 승인본으로 확정됩니다.
- 수정 요청을 하시면, 수정본(v2, v3…)이 올라올 때 메일로 다시 알려드립니다.
- 3일간 회신이 없으면 안내 메일이 한 번 더 갑니다.

### ⑤ 최종 승인본
- 화면 위에 **"✔ 최종 승인본입니다 (수정 불가)"** 가 보이면 확정된 파일입니다. 인쇄·생산은 **반드시 이 파일**로 진행해 주세요.
- 메일·메신저로 받은 예전 파일이나 AI 원본 대신, 포털의 최종 승인본을 기준으로 삼아 주세요.

### 이런 화면이 나오면
| 화면 | 의미 / 할 일 |
|---|---|
| 기간이 만료된 링크입니다 | 열람 기간이 끝났습니다. 담당자에게 새 링크를 요청하세요. |
| 사용이 중지된 링크입니다 | 링크가 폐기되었습니다. 담당자에게 문의하세요. |
| 새 버전을 준비하고 있습니다 | 수정본을 작업 중입니다. 발송되면 메일로 알려드립니다. |
| 비밀번호를 잊었을 때 | 보안상 다시 알려드릴 수 없어 **새 링크·비밀번호를 발급**해 드립니다. 담당자에게 연락 주세요. |
